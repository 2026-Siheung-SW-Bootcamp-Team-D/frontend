# 퍼블리싱 핵심 흐름 완성 설계

## 목표

지도·장소 검색·교통 API를 호출하지 않는 퍼블리싱 단계에서도, 연당의 P0 사용자 흐름을 끝까지 조작할 수 있게 한다.

## 결정

- 모임 상태는 `BoardProvider`가 단일 진실로 관리한다. 생성·입장·출발지·장소·선택 변경은 모두 이 상태를 갱신한다.
- 외부 조회는 결정형 목 결과로 대체한다. 검색어에 `없음`, `오류`, `제한`을 포함하면 각각 빈 결과·오류·요청 제한 상태를 보여 준다.
- 지도 SDK는 연결하지 않는다. 지도 패널 클릭으로 좌표를 선택하고 탐색 핀과 반경을 시각화한다.
- 모든 하위 화면은 URL에서 받은 모임 ID로 복귀한다. 하드코딩된 ID는 제거한다.
- 데스크톱에서는 지도와 목록을 나란히, 모바일에서는 지도와 바텀시트를 순서대로 노출한다.

## 흐름

1. 홈에서 최근 모임을 열거나 이름·닉네임으로 새 모임을 만든다.
2. 생성된 코드 또는 링크로 입장하고, 닉네임과 출발지를 선택한다.
3. 검색·외부 출처·직접 핀으로 장소를 추가하고 목록·지도에서 같은 선택 상태를 확인한다.
4. 지역 제안 결과 또는 자유 지도 좌표에서 주변을 탐색해 장소를 추가한다.

## 검증

자동 테스트 러너가 없으므로 `npm run lint`, `npm run build`, 개발 서버의 주요 흐름 수동 검증을 완료 조건으로 삼는다.
